# dms_demo

## Ozellar Marine — Vessel Document Management System (DMS)

Replicated and rebranded Vessel Document Management System for **Ozellar Marine**.

### Project Structure
- `ozellar_dms_frontend/` — SPFx React Web Part frontend (SharePoint Framework)
- `ozellar_dms_backend/` — FastAPI Python backend service with PostgreSQL & Microsoft Graph integration
